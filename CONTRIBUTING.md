# Contributing

Spec corrections and new products are the most useful contributions.

1. Fork the repo and create a branch from `main`.
2. Install and start the dev server: `npm install && npm run dev`.
3. Make your change. Products and category specs live in `src/data/products.ts`, the types in `src/types/index.ts`.
4. Run `npm run build`. It typechecks and builds; it has to pass.
5. Open a pull request and name the source for any spec you changed or added.

Keep changes small and focused. For larger changes (new categories, new brands, layout changes), open an issue first.
